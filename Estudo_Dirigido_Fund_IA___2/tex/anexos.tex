\section{Reprodução}

O \texttt{README.md} do repositório lista os comandos que geram cada tabela e
figura deste relatório:
\begin{verbatim}
python3 -m unittest discover -s tests   # testes (fitness, incremental, OX/PMX)
python3 src/experimentos.py todos       # grava resultados/*.csv e *_hist.json
python3 src/analise.py                  # gera relatorio/tabelas e figures/tp2
\end{verbatim}
